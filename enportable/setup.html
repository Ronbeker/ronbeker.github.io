⚠ Local use only

This setup page only runs on localhost or file:// — never enter your JSONBin key on the public site.

Credential vault setup

Runs entirely in this browser tab. Your JSONBin key is encrypted with your passphrase (PBKDF2-SHA256 · 310k iterations · AES-256-GCM) and written to vault.json. The key itself is never stored or sent anywhere except to JSONBin's API if you tick "create bin".
✔ vault.json downloaded. Move it into the enportable/ folder next to index.html, commit, push. Then open the live page and unlock with your passphrase.
Losing the passphrase = re-run this setup (your key stays in your JSONBin dashboard). Previously synced cloud data becomes unreadable — keep the app's JSON backups.
