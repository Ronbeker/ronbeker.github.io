f(0) = {ε},  f(1) = {ε}.

Every letter is replaced by the language {ε}, so every word of L is mapped to ε: if L ≠ ∅ then f(L) = {ε}, and if L = ∅ there is nothing to substitute, so f(L) = ∅.

Since L is a regular language there exists a DFA A = (Q_A, Σ, δ_A, q_s, F) such that L(A) = L.

For every p, q ∈ Q_A, define LAp,q = {w | δ′_A(p,w) = q} — a regular language (take p as initial state and q as the only accepting state).

Note that L = ⋃p,q∈Q, f∈F LAq_s,p · LAp,q · LAq,f.

Since LAq,f is regular, (LAq,f)R = {w | wR ∈ LAq,f} is also regular (closure under reverse).

Note that f(LAp,q) = {ε} if LAp,q ≠ ∅ and ∅ otherwise, where f is the regular substitution from section 1.1; f(LAp,q) is regular (closure under regular substitution).

Note that:

Op₁(L) = ⋃p,q∈Q, f∈F (LAq,f)R · LAq_s,p · f(LAp,q)

which is a regular language (finite union of concatenations of regular languages).

The concatenation with f(LAp,q) is needed to handle the case that A has no path from p to q (concatenating with {ε} keeps the language; concatenating with ∅ empties it). For example, in the following DFA:

‏L(A) = ∅, ואין מסלול מ-p ל-q

L(A) = ∅ but ⋃ (LAq,f)R · LAq_s,p = {00,01,10,11} ≠ Op₁(L(A)), while with the extra factor ⋃ (LAq,f)R · LAq_s,p · f(LAp,q) = ∅ = Op₁(L(A)).

  • ⟨M,w⟩ ∈ ATM: M accepts w, so N_{M,w} accepts every x ∈ Σ* — the second condition holds, so f(⟨M,w⟩) ∈ L.
  • ⟨M,w⟩ ∉ ATM: N_{M,w} does not accept every x (it never accepts), and no x is accepted by N_∅ — neither condition holds, so f(⟨M,w⟩) ∉ L.

L ∉ RE: we show ATM ≤m L (ATM ∉ RE, therefore L ∉ RE):

f(⟨M, w⟩) = ⟨N_∅, N_{M,w}⟩ where:

N_∅: "On input x: Reject."

N_{M,w}: "On input x:
1. Run M on w for |x| steps.
2. If M didn't accept w during these steps, accept.
3. Otherwise, reject."

Correctness:

  • ⟨M,w⟩ ∈ ATM: M doesn't accept w, so for every x, M doesn't accept w within |x| steps, and N_{M,w} accepts x in line 2. Hence N_{M,w} accepts all inputs and f(⟨M,w⟩) ∈ L.
  • ⟨M,w⟩ ∈ ATM: M accepts w within some finite k steps. For |x| < k, N_{M,w} accepts x; for |x| ≥ k it rejects. Therefore L(N_{M,w}) = ⋃n<k Σn ≠ Σ* — it does not accept all inputs. In addition ∄x accepted by N_∅. So f(⟨M,w⟩) ∉ L.
