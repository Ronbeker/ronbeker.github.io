A ∉ RE: we reduce HALTTM ≤m A:

f(⟨M, w⟩) = ⟨N⟩, where:

N: "On input x:
1. Run M on w.
2. Reject."

f is clearly computable as it only writes the encoding of N on the tape.

  • ⟨M,w⟩ ∈ HALTTM ⟹ M does not halt on w ⟹ N does not halt on any input ⟹ N does not reject any input ⟹ ⟨N⟩ ∈ A.
  • ⟨M,w⟩ ∉ HALTTM ⟹ M halts on w ⟹ N rejects all inputs (in particular w′·w′ for palindromes w′) ⟹ ⟨N⟩ ∉ A.

Since HALTTM ∉ RE, also A ∉ RE (and in particular A ∉ R).

A ∈ coRE: we build a recognizer S for A = {⟨M⟩ | M is a TM and ∃w ∈ PAL s.t. M rejects w·w}:

S: "On input ⟨M⟩:
1. For i = 1, 2, …:
   1.1. For j = 0, 1, …, i:
      1.1.1. For every x ∈ Σ^j in lexicographical order:
         1.1.1.1. If x = x^R:
            1.1.1.1.1. Run M on xx for i steps.
            1.1.1.1.2. If M rejected, accept."

Correctness:

  • ⟨M⟩ ∉ A: for every palindrome w, M does not reject ww. Hence S never accepts in line 1.1.1.1.2 — and since that is the only accepting line, S does not accept ⟨M⟩ (it never halts).
  • ⟨M⟩ ∈ A: there exists w ∈ PAL such that M rejects ww in some number k of steps. Each execution of line 1.1.1.1.1 terminates in finite time, and the sets iterated in lines 1.1 and 1.1.1 are finite — so each iteration of the outer loop terminates. Hence S accepts ⟨M⟩ at the latest when i = max{|w|, k}, j = |w| and x = w.
