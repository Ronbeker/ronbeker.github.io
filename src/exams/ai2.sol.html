Then f(L) = {stut(w) | w ∈ L} = stut(L), and regular languages are closed under regular substitution — so stut(L) is regular.

We construct a recognizer S for L:

S: "On input z:
1. If z is not of the form ⟨M, k⟩ — accept.   (syntactic check, decidable)
2. For i from 0 to ∞:
   2.1. Counter := 0.
   2.2. For every x with |x| ≤ i, in lexicographical order:
      2.2.1. Run M on x for i steps.
      2.2.2. If M accepted — Counter++.
   2.3. If Counter ≥ k+1 — accept."

Correctness:

  • ⟨M,k⟩ ∈ L: there exist k+1 distinct accepted words x₁,…,x_{k+1}; let s be the maximal number of steps needed to accept any of them and ℓ the maximal length. At iteration i = max{s, ℓ} the sweep counts at least k+1 acceptances and S accepts. Every iteration is finite (finitely many words, bounded simulations), so this iteration is reached.
  • ⟨M,k⟩ ∉ L (i.e. |L(M)| ≤ k): no sweep can ever count k+1 distinct accepted words, so S never accepts.
