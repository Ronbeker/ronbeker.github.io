Define L′ = {xŷz | |x| = |y|} and note that L₃ = L′ ∩ L₁. Since L₁ is regular (section 1.1), if we prove that L′ is a context-free language then we prove that L₃ is also a context-free language (intersection between a regular language and a context-free language).

Define a context-free grammar G = (V, Σ, S, R) for L′:

V = {S, A, B, C, D}, Σ = {0, 1, 0̂, 1̂}

S → AB
A → CAD | ε
B → CB | ε
C → 0 | 1
D → 0̂ | 1̂

Therefore L′ is a context-free language and L₃ = L′ ∩ L₁ is also a context-free language.

Let DFA A = (Q_A, Σ, δ_A, q_{sA}, F_A) such that L(A) = L (L is a regular language).

Define PDA P = (Q_P, Σ_P, Γ_P, δ_P, q_{sP}, F_P) as follows:

Q_P = Q_A × {1,2,3} ⊎ {q_{sP}, f_P}, Σ_P = {0,1,0̂,1̂}, Γ = {x, $} and F_P = {f_P}.

  • ∀f ∈ F_A × {3} we add the transition δ_P(f, ε, $) = {(f_P, ε)}.
  • ∀q ∈ Q_A we add the transitions δ_P((q,1), ε, ε) = {((q,2), ε)} and δ_P((q,2), ε, ε) = {((q,3), ε)}.

f(⟨M, w⟩) = ⟨N_{M,w}, D⟩ where:

D: "On input x:
1. If x = "00", accept.

Correctness: note that L(D) = {00}.

  • f is a computable function: to compute f all that needs to be done is to encode the description (string) of the TM N_{M,w} and the DFA D. The strings are of finite length and the encoding process takes finite time, and eventually the TM halts with the output ⟨N_{M,w}, D⟩.
  • ⟨M,w⟩ ∈ ATM: M accepts w, therefore N_{M,w} rejects (and halts) on every x, y ∈ Σ*; in particular N_{M,w} halts on x = 0 and rejects y = 0, and xy = 00 ∈ L(D). Therefore f(⟨M,w⟩) = ⟨N_{M,w}, D⟩ ∈ L.
  • ⟨M,w⟩ ∉ ATM: M does not accept w, therefore N_{M,w} does not halt on any x ∈ Σ*. Therefore ∄x ∈ Σ* such that N_{M,w} halts on x, and f(⟨M,w⟩) = ⟨N_{M,w}, D⟩ ∉ L.

L ∈ RE: we construct a recognizer M_L for L.

M_L: "On input ⟨M, D⟩:
1. For i from 0 to ∞:
   1.1. For j from 0 to i:
      1.1.1. For every x ∈ Σ^j in lexicographical order:
         1.1.1.1. Run M on x for i steps.
         1.1.1.2. If M accepted or rejected (halted) x:
            1.1.1.2.1. For h from 0 to i:
               1.1.1.2.1.1. For every y ∈ Σ^h in lexicographical order:
                  1.1.1.2.1.1.1. Run M on y for i steps.
                  1.1.1.2.1.1.2. If M rejected y:
                     1.1.1.2.1.1.2.1. Run D on xy.
                     1.1.1.2.1.1.2.2. If D accepted xy, accept."
  • ⟨M,D⟩ ∈ L: there exist words x, y ∈ Σ* such that M halts on x and rejects y, and D accepts xy. Among all such pairs consider the one minimizing k = max{k_x, k_y}, where k_x, k_y are the number of steps in which M halts on x and rejects y respectively (ties broken by length and lexicographic order of x, then of y). For every iteration i < k, every candidate pair fails at least one of the three conditions, so nothing is accepted early; at iteration i = k the machine runs M on x and on y for k steps, sees the halt and the rejection, runs D on xy and accepts. Therefore after a finite number of steps M_L accepts ⟨M,D⟩.
  • ⟨M,D⟩ ∉ L: for every pair x, y ∈ Σ* one of the following holds — M does not halt on x, M does not reject y, or D does not accept xy. Therefore M_L never reaches an accepting iteration.
