b.  L₁ = L₂ = {anbn | n ≥ 0}.

L₁ is context-free, so it has a PDA A = (Q_A, Σ_A, Γ_A, δ_A, q_{sA}, F_A) with L(A) = L₁; L₂ is regular, so it has a DFA B = (Q_B, Σ_B, δ_B, q_{sB}, F_B) with L(B) = L₂.

We construct P = (Q_P, Σ_P, Γ_P, δ_P, q_{sP}, F_P):

Q_P = Q_A ⊎ (Q_B × {1,2}), Σ_P = Σ_A ∪ Σ_B, Γ_P = Γ_A ⊎ Q_B, q_{sP} = (q_{sB}, 1), F_P = F_B × {2}.

δ_P contains all the transitions of δ_A, plus:

  • For each δ_B(p, b) = q: add δ_P((p,1), b, ε) = {((q,1), ε)} and δ_P((p,2), b, ε) = {((q,2), ε)} — simulating B on u (phase 1) and on w (phase 2).
  • For each p ∈ Q_B and each f ∈ F_A: add δ_P((p,1), ε, ε) = {(q_{sA}, p)} and δ_P(f, ε, p) = {((p,2), ε)}.

How P works: it simulates B on the prefix u; at a nondeterministically chosen point it pushes the current state p of B onto the stack and jumps into the PDA A to read v ∈ L₁; when A reaches an accepting state, P pops the saved state p and resumes the simulation of B on w exactly where it stopped. Acceptance requires finishing in F_B — i.e. uw ∈ L₂ and v ∈ L₁. (The transitions of A never touch the saved state at the bottom, since A only pops symbols it pushed itself.)

L ∉ R, L ∉ coRE: we show ATM ≤m L (ATM ∉ coRE, therefore L ∉ coRE and L ∉ R):

f(⟨M, w⟩) = ⟨D, N_{M,w}⟩ where:

D: "On input x:
1. If x = "1", accept.
2. Otherwise, reject."

N_{M,w}: "On input x: Run M on w and do as M does."

Correctness: note that min{|w| : w ∈ L(D)} = 1 (and L(D) ≠ ∅).

  • f is a computable function (finite syntactic encoding).
  • ⟨M,w⟩ ∈ ATM: L(N_{M,w}) = Σ*, so |L(N_{M,w})| ≥ 1 — therefore f(⟨M,w⟩) ∈ L.
  • ⟨M,w⟩ ∉ ATM: L(N_{M,w}) = ∅, so |L(N_{M,w})| = 0 < 1 — therefore f(⟨M,w⟩) ∉ L.

L ∈ RE: we construct a recognizer M_L for L:

M_L: "On input ⟨D, M⟩:
1. Define Length = 0
2. For k = 0 to ∞:
   2.1. For every x ∈ Σ^k in lexicographical order:
      2.1.1. Run D on x.
      2.1.2. If D accepted:
         2.1.2.1. Length = k.
         2.1.2.2. If k = 0, accept.
         2.1.2.3. Otherwise, goto line 3.
3. For i = 0 to ∞:
   3.1. Define Counter = 0.
   3.2. For j = 0 to i:
      3.2.1. For every x ∈ Σ^j in lexicographical order:
         3.2.1.1. Run M on x for i steps.
         3.2.1.2. If M accepted:
            3.2.1.2.1. Counter++.
            3.2.1.2.2. If Counter = Length, accept."

Correctness:

  • ⟨D,M⟩ ∈ L: lines 1–2 find the shortest word of L(D) (a DFA — every run halts), setting Length = min{|w| : w ∈ L(D)}; if it is 0 we accept at once. Otherwise |L(M)| ≥ Length, so there exist Length distinct words accepted by M; let s be the maximal number of steps needed to accept the "cheapest" such set. At iteration i = s, all of them are accepted within the same sweep and Counter reaches Length — M_L accepts.
  • ⟨D,M⟩ ∉ L: if L(D) = ∅ the loop in line 2 never finds an accepted word and M_L runs forever. Otherwise |L(M)| < Length: no sweep can ever count Length distinct accepted words, so the condition in 3.2.1.2.2 never holds and M_L never halts.

A is a finite set, therefore both A ∖ L₁ and A ∩ L₁ are finite languages and hence decidable.

Since L₂ is non-trivial, there exist w_{in} ∈ L₂ and w_{out} ∉ L₂.

We show L₁ ≤m L₂ by constructing a TM G computing a mapping function g:

G: "On input x:
1. If x ∈ A ∖ L₁, return w_out.
2. If x ∈ A ∩ L₁, return w_in.
3. Otherwise, return f(x)."

g is computable — lines 1–2 run deciders of finite languages, line 3 runs the computable f.

  • x ∈ L₁: if x ∈ A ∩ L₁ we return w_{in} ∈ L₂; if x ∈ L₁ ∖ A we return f(x) ∈ L₂ (by the property of f outside A).
  • x ∉ L₁: if x ∈ A ∖ L₁ we return w_{out} ∉ L₂; otherwise x ∉ A and we return f(x) ∉ L₂.

In every case x ∈ L₁ ⟺ g(x) ∈ L₂ — so L₁ ≤m L₂.
