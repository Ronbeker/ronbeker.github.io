A word of Rot(L) has the form x·σ₁ where σ₁x ∈ L: the first letter σ₁ moved to the end.

For every σ ∈ Σ let q_σ = δ(q_s, σ) — the state reached after reading the (removed) first letter. Then σx ∈ L iff x ∈ LAq_σ,f for some f ∈ F. Therefore:

Rot(L) = ⋃σ∈Σ, f∈F LAq_σ,f · {σ}

Each LAq_σ,f is regular (adjust initial/accepting states of A), {σ} is regular, and regular languages are closed under concatenation and finite union — so Rot(L) is regular.

Call a pair of states (p, q) good if there exists k ≥ 0 such that some word of length k leads from q_s to p, and some word of length k leads from q into F.

Note that y ∈ Mid(L) iff there exists a good pair (p,q) with y ∈ LAp,q: the prefix x (of length k) takes q_s to p, then y takes p to q, then the suffix z (of the same length k) takes q into F.

Therefore:

Mid(L) = ⋃(p,q) good LAp,q

The set of good pairs is some subset of the finite set Q × Q — it exists even if we do not compute it (for regularity it suffices that an automaton exists). Each LAp,q is regular, and a finite union of regular languages is regular — so Mid(L) is regular.

(One can in fact compute the good pairs: the sequence of set-pairs (states reachable from q_s in exactly k steps, states reaching F in exactly k steps) takes finitely many values, so the union over k stabilizes — but the existence argument already completes the proof.)

Define PDA P = (Q_P, Σ, Γ, δ_P, q_{sP}, F_P):

Q_P = {q_{sP}, q_{acc}} ⊎ Q ⊎ (Q × F × Q),  Γ = Σ ⊎ {$},  F_P = {q_{acc}}.

A phase-2 state (c, f, m) carries: the current state c of a backward run of A, the guessed accepting state f, and the remembered midpoint m.

  • δ_P(q_{sP}, ε, ε) = {(q_s, $)} — push a bottom marker, start simulating A.
  • Phase 1 (reading x): for every transition δ(p, σ) = q of A: add δ_P(p, σ, ε) = {(q, σ)} — simulate A forward and push every letter read.
  • Guess the midpoint: for every p ∈ Q and every f ∈ F: add δ_P(p, ε, ε) = {((f, f, p), ε)} — remember the midpoint p and start a backward run at the guessed final state f.
  • Phase 2 (reading yR): for every transition δ(p′, σ) = q′ of A: add δ_P((q′, f, m), σ, σ) = {((p′, f, m), ε)} — each input letter undoes one A-transition, and pops one pushed letter (enforcing |x| = |y|).
  • Accept: for every m ∈ Q, f ∈ F: add δ_P((m, f, m), ε, $) = {(q_{acc}, ε)} — the backward run has returned exactly to the midpoint and the stack is empty.

Why it works: a word is accepted iff it can be split as x·(yR) such that q_s →x→ m (phase 1), and reading yR backwards from some f ∈ F arrives at m — i.e. the forward run m →y→ f exists, so xy ∈ L; the stack discipline (push per letter of x, pop per letter of yR, ‏$ exposed exactly at the end) gives |x| = |y|. Hence L(P) = Fold(L) — context-free.

M_L: "On input ⟨M₁, M₂⟩:
1. For i from 0 to ∞:
   1.1. For every x with |x| ≤ i, in lexicographical order:
      1.1.1. Run M₁ on x for i steps.
      1.1.2. Run M₂ on x for i steps.
      1.1.3. If both accepted — accept."

Correctness:

  • ⟨M₁,M₂⟩ ∈ L: there exists x ∈ L(M₁) ∩ L(M₂); let k₁, k₂ be the numbers of steps in which the machines accept it. At iteration i = max{|x|, k₁, k₂} both simulations discover the acceptance and M_L accepts. Every earlier iteration performs a finite amount of work (finitely many words, bounded simulations), so the iteration is reached after finitely many steps.
  • ⟨M₁,M₂⟩ ∉ L: no word is accepted by both, so the condition in line 1.1.3 never holds and M_L never accepts (it runs forever).
