רדוקציות מיפוי

מודלים חישוביים — פרק 12 (הרצאה 12 + תרגול 12)

רדוקציית מיפוי — ההגדרה

רדוקציית מיפוי — ‏A ≤m B אם קיימת פונקציה ניתנת לחישוב f: Σ* → Σ* (מ"ט שעוצרת על כל קלט ומחזירה פלט) כך שלכל w:
w ∈ A  ⟺  f(w) ∈ B

אינטואיציה: "‏A היא מקרה פרטי מחופש של B" — מי שיודע לענות על B, עונה על A דרך התרגום f. שימו לב לשקילות הדו-כיוונית: גם "כן"→"כן" וגם "לא"→"לא".

מה ≤m משמר — כללי ההעברה

אם A ≤m B אז:
  • B ∈ R ⟹ A ∈ R  (שקול: ‏A ∉ R ⟹ B ∉ R)
  • B ∈ RE ⟹ A ∈ RE  (שקול: ‏A ∉ RE ⟹ B ∉ RE)
  • B ∈ coRE ⟹ A ∈ coRE  (שקול: ‏A ∉ coRE ⟹ B ∉ coRE)
השייכוּת יורדת עם כיוון החץ; הקושי מטפס נגדו.

ההוכחה בת שורה: מכריע/מזהה ל-B + חישוב f = מכריע/מזהה ל-A ("חשב f(w), שאל את B").

תבנית הכתיבה המלאה של רדוקציה

ארבעת הרכיבים (הפורמט הרשמי המדויק)

  1. הכרזה: "נראה ATM ≤m L (‏ATM ∉ coRE, לכן L ∉ coRE ו-L ∉ R)".
  2. הגדרת f: ‏f(⟨M,w⟩) = ⟨NM,w⟩ (או זוג/שלשה), עם פסאודו-קוד מלא של המכונות הנבנות.
  3. חישוביות: "‏f ניתנת לחישוב: כל שנדרש הוא לכתוב את הקידוד של NM,w — מחרוזת סופית שנבנית בזמן סופי." (משפט קבוע — אבל חובה לכתוב אותו!)
  4. נכונות דו-כיוונית: ‏⟨M,w⟩ ∈ ATM ⟹ f(⟨M,w⟩) ∈ L וגם ⟨M,w⟩ ∉ ATM ⟹ f(⟨M,w⟩) ∉ L — שני כיוונים מפורשים, כל אחד עם הנימוק שלו.
רוב הנקודות הולכות לאיבוד ברכיב 4: כותבים כיוון אחד ושוכחים שהשני אינו "אותו דבר בהיפוך" — ב"לא מקבלת" מסתתרות דחייה וגם לולאה, ולכל אחת התנהגות אחרת של NM,w. בדקו את שתיהן.

HALT_TM — הרדוקציה הראשונה

HALTTM = {⟨M,w⟩ | M halts on input w}

‏ATM ≤m HALTTM

‏f(⟨M,w⟩) = ⟨N, w⟩ כאשר:

N: "On input x:
1. Run M on x.
2. If M accepted — accept.
3. If M rejected — loop."

נכונות: אם M מקבלת את w — ‏N עוצרת על w (מקבלת) ⇒ בשפה. אם לא (דוחה או מתלולאת) — ‏N על w מתלולאת (בשורה 3 או כבר בשורה 1) ⇒ לא בשפה. ✓

הטריק: "המרת דחייה ללולאה" מאחדת את שתי צורות ה"לא" לצורה אחת שנראית ל-HALT. מסקנה: ‏HALTTM ∈ RE ∖ R — בדיוק כמו ATM (‏RE מסימולציה-עד-עצירה; לא R מהרדוקציה).

E_TM — רדוקציה עם משלים

‏ATM ≤m ETM (ולכן ATM ≤m ETM)

‏f(⟨M,w⟩) = ⟨NM,w⟩ כאשר:

N_{M,w}: "On input x:
1. Run M on w.   (ignoring x!)
2. If M accepted — accept."

אם M מקבלת את w: ‏L(N) = Σ* ≠ ∅; אחרת L(N) = ∅. לכן ⟨M,w⟩ ∈ ATM ⟺ ⟨N⟩ ∉ ETM. ✓

שתי נקודות מבניות: (1) התעלמות מהקלט — ‏N מקודדת את השאלה על (M,w) בתוך ההתנהגות הגלובלית שלה; ‏L(N) קופצת בין ∅ ל-Σ*. (2) רדוקציה למשלים — ‏A ≤m B שקולה ל-A ≤m B (אותה f!). מסקנה: ‏ETM ∈ coRE ∖ R.

האם ההיפוך המצוין פה מפר את "אסור להפוך מזהה"? לא — לא הפכנו מכונה; בחרנו לאיזו שפה (B או המשלים שלה) ממפים. משחקי המשלים האלה הם בדיוק הקווים העיליים שראינו במבחני 2024 — לקרוא אותם בדקדקנות.

גלריית המכונות המתוכנתות N_{M,w}

כל רדוקציה בונה מכונה שמקודדת את השאלה. הגלריה מהמבחנים:

‏N על קלט x‏L(N) כש-M מקבלת את w‏L(N) כשלאשימש ב…
הרץ M על w; ענה כמוהΣ*∅‏E_TM, ‏2023ב ש2
הרץ M על w; אם קיבלה — קבל; אחרת לולאהΣ*∅ (בלי לעצור)‏HALT-גרסאות
אם קיבלה — דחה; אחרת לולאה∅ ועוצרת-דוחה∅ בלי לעצור‏2024א ש2 (עם D)
הרץ M על w ל-|x| צעדים; קבל אם לא קיבלהסופית (≠ Σ*)Σ*‏2024ב ש2 (מ-ATM)

לצד N מצרפים לעיתים רכיב קבוע — DFA קטן (‏L(D)={00} ב-2024א, ‏{1} ב-2023ב) — שמכייל את התנאי המספרי/מבני של שפת היעד.

לקרוא את הגלריה = לדעת לכתוב את הרדוקציה הבאה: בוחרים את ההתנהגות הגלובלית שמפרידה נכון (‏∅ מול Σ*, עוצרת מול לא, סופית מול הכול), ומכוונים אותה לתנאי של שפת היעד.

הטריק של התקציב: רדוקציות מ־Ā_TM

להוכיח L ∉ RE — מראים ATM ≤m L. הקושי: המכונה הנבנית צריכה "לזהות אי-קבלה" — שאין לה עד. הפתרון: תקציב הצעדים.

השלד של 2024ב ש2 (החלק השני)

N_{M,w}: "On input x:
1. Run M on w for |x| steps.
2. If M didn't accept within these steps — accept.
3. Otherwise — reject."

‏⟨M,w⟩ ∈ ATM ⟹ אף תקציב לא יגלה קבלה ⟹ ‏L(N) = Σ* ("‏N מקבלת כל קלט" — התנאי של שפת היעד שם). ‏⟨M,w⟩ ∈ ATM (קבלה תוך k צעדים) ⟹ ‏L(N) = {x : |x| < k} — סופית, לא Σ*. ✓

התבנית הכללית: תכונת-"לעולם לא" (אי-קבלה, אי-עצירה) הופכת לתכונת-"לכל תקציב", והיא נבדקת קלט-קלט עם |x| כתקציב. כשפוגשים שפה שהתנאי שלה הוא "‏M מקבלת את כל הקלטים" או "‏L(M) = Σ*" — כמעט תמיד הרדוקציה הזו בסביבה.

REG_TM ו־EQ_TM — מחוץ לשני העולמות

REGTM = {⟨M⟩ | L(M) is regular},  EQTM = {⟨M₁,M₂⟩ | L(M₁) = L(M₂)} — שתיהן מחוץ ל-RE ∪ coRE.

הרעיון (על REG): בונים NM,w שמחליפה בין שפה רגולרית לשפה לא-רגולרית לפי קבלת w:

N_{M,w}: "On input x:
1. If x has the form 0ⁿ1ⁿ — accept.
2. Otherwise: run M on w; if M accepted — accept."

‏M מקבלת את w ⟹ ‏L(N) = Σ* (רגולרית!); לא מקבלת ⟹ ‏L(N) = {0n1n} (לא רגולרית). זה נותן ATM ≤m REGTM ⟹ ‏∉ RE; ובחילוף התפקידים (רגולרית כשלא-מקבלת) — ‏ATM ≤m REGTM ⟹ ‏∉ coRE. שתי רדוקציות = מחוץ לשניהם.

‏EQTM — אותו משחק מול מכונה קבועה: השוואה ל-M∅ נותנת את הצד האחד, ל-MΣ* את השני. וכך גם PALTM ו-L∞ מדף הנוסחאות — כל תכונה סמנטית "עשירה" נופלת לשני הצדדים (וזה בדיוק נושא פרק 13: משפט רייס).

תכונות ≤m — טרנזיטיביות ומשלים

  • טרנזיטיביות: ‏A ≤m B ≤m C ⟹ A ≤m C (הרכבת פונקציות חישוביות — חישובית). מאפשרת "לרדת" מ-HALT במקום מ-A_TM כשנוח.
  • משלים: ‏A ≤m B ⟺ A ≤m B — אותה f בדיוק (השקילות נשמרת תחת שלילה בשני הצדדים).
  • רפלקסיביות: ‏A ≤m A (הזהות). וגם: כל A ∈ R ניתנת לרדוקציה לכל שפה לא-טריוויאלית (המכריע בוחר win/wout) — הנקודה של 2024ב ש3.4!
  • אי-סימטריה מהותית: ‏A ≤m B לא גורר B ≤m A — קושי זורם רק בכיוון אחד.

שתי הפתעות מהמבחנים

‏‏L ≤m L̄ אפשרית גם לכריעות (2024ב ש3.4: זוגי↔אי-זוגי עם f(w)=1w) — אל תניחו שרדוקציה-למשלים מעידה על קושי. ורדוקציה "כמעט-מכל-מקום" (2023ב ש3.6): ‏f שמקיימת את התנאי רק מחוץ לקבוצה סופית A — ניתנת לתיקון עם מכריעי A∩L₁, A∖L₁ ועדים win/wout.

טעויות כיוון קלאסיות

  • רדוקציה הפוכה: להוכיח ש-B קשה — חייבים קשה ≤m B. להראות B ≤m ATM אומר רק ש-B "לא יותר קשה מ-A_TM" — כלום. (בדיקה עצמית: הידועה משמאל!)
  • כיוון ההעברה: שייכות יורדת מ-B ל-A. ‏"‏A ∈ R ו-A ≤m B ⟹ ‏B ∈ R" — שגוי (כל כריעה נמפית ל-A_TM!).
  • בחירת מחלקה שגויה לשלילה: ‏ATM ≤m B שולל ‏coRE (ו-R); הוא לא שולל RE — ‏B בהחלט יכולה להיות ב-RE (‏A_TM עצמה!). לשלילת RE — רדוקציה מ-ATM.
  • ‏f "כמעט חישובית": ‏f שמפעילה בעצמה בדיקה לא-כריעה ("אם M עוצרת אז…") — פסולה. ‏f חייבת להיות מכריע-מחשב אמיתי; כל הקושי צריך לשבת בתוך המכונה הנבנית, לא בתוך f.
משפט הבדיקה לפני הגשה: "מהידועה אל הנאשמת; השייכות נגד הכיוון; המחלקה הנשללת תואמת את הידועה; ו-f עצמה תמימה". ארבע בדיקות של עשר שניות.

רדוקציות טיורינג — מבט קצר

רדוקציית טיורינג — ‏A ≤T B: קיים מכריע ל-A שמורשה לקרוא לאורקל של B (תשובות מיידיות לשאלות "האם x ∈ B?") — מספר פעמים, ועם עיבוד חופשי של התשובות.

ההבדל מ-≤m: מיפוי הוא "שאלה אחת, בלי לגעת בתשובה"; טיורינג מרשה הכול. לכן:

  • ‏A ≤m B ⟹ A ≤T B (מקרה פרטי).
  • ‏ATM ≤T ATM (שואלים את האורקל והופכים) — אבל ATM ≰m ATM! (‏≤m היה גורר ATM ∈ coRE.) ההיפוך שאסור ב-≤m — מותר ב-≤T.
  • ‏≤T משמר רק כריעות (‏B ∈ R ⟹ A ∈ R) — לא RE/coRE. לכן לשאלות RE/coRE במבחן חובה ≤m דווקא.
לב הפרק: ‏≤m = תרגום חישובי ששומר שייכות דו-כיוונית; הקושי מטפס נגד החץ; המכונות המתוכנתות (עם או בלי תקציב) הן ארגז הכלים; שתי רדוקציות משליכות שפה אל מחוץ לשני העולמות; והכיוון — תמיד מהידועה אל הנאשמת.
