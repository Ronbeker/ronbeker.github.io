דף נוסחאות והגדרות

הנוסח שמצורף רשמית למבחני 2023–2024 (מתורגם ומורחב קלות) — כדאי להכיר אותו היטב: הוא זמין לכם בזמן המבחן

אוטומטים סופיים

אוטומט סופי דטרמיניסטי (DFA) — חמישייה A = (Q, Σ, δ, qs, F) כאשר:
  • Q — קבוצה סופית של מצבים.
  • Σ — קבוצה סופית, האלף־בית.
  • δ: Q × Σ → Q — פונקציית המעברים.
  • qs ∈ Q — המצב ההתחלתי.
  • F ⊆ Q — קבוצת המצבים המקבלים.
אוטומט סופי לא־דטרמיניסטי (NFA) — חמישייה B = (Q, Σ, δ, qs, F), זהה ל־DFA פרט לפונקציית המעברים:
δ: Q × Σε → P(Q)  ,  Σε = Σ ∪ {ε}
כלומר מכל מצב, על כל אות (או על ε), עוברים לקבוצת מצבים אפשריים.
שפה רגולרית — שפה נקראת רגולרית אם ורק אם קיים אוטומט סופי שמזהה אותה (שקול: קיים ביטוי רגולרי שמתאר אותה; שקול: קיים דקדוק רגולרי שיוצר אותה).

המרות בין מודלים רגולריים

NFA ← DFA (בניית תת־הקבוצות)

בהינתן N = (QN, ΣN, δN, qsN, FN) נבנה D = (QD, ΣD, δD, qsD, FD):

  • QD = P(QN) (קבוצת החזקה).
  • ΣD = ΣN.
  • לכל R ∈ QD ולכל σ ∈ ΣD: δD(R, σ) = ⋃r∈R E(δN(r, σ)), כאשר E(R) היא סגירת ה־ε — כל המצבים שנגישים מ־R במעברי ε בלבד.
  • qsD = E(qsN).
  • FD = {R ∈ QD | R ∩ FN ≠ ∅}.

Regex ← NFA

  1. מציירים NFA בן שני מצבים שהמעבר ביניהם מסומן בביטוי r כולו.
  2. מעבר שמסומן r + s מוחלף בשני חיצים מקבילים — אחד r ואחד s.
  3. מעבר שמסומן rs מוחלף בשני חיצים עוקבים דרך מצב ביניים חדש.
  4. מעבר שמסומן r* מוחלף במבנה: ε פנימה, לולאת r עצמית, ε החוצה.
  5. ממשיכים עד שכל התוויות הן אותיות מ־Σε.

NFA ← Regex : דרך GNFA (אלימינציית מצבים)

שלב א — הפיכה ל־GNFA:

  • מצב התחלתי חדש s עם δ(s, ε) = qs, כך שמההתחלה יוצאים חיצים בלבד.
  • מצב מקבל יחיד חדש f: לכל q ∈ F מוסיפים δ(q, ε) = f, וקובעים F = {f}.
  • בין כל זוג מצבים יש בדיוק חץ אחד: חיצים מקבילים מוחלפים בסכום (+) של התוויות; אם אין חץ — מוסיפים חץ בתווית ∅.

שלב ב — אלימינציה: מסלקים בכל פעם מצב k ≠ s, f, ולכל זוג (i, j) מעדכנים:

new(i,j) = old(i,j) + old(i,k)·old(k,k)*·old(k,j)

תזכורת: ∅* = {ε}. בסוף נשארים רק s ו־f, והתווית על החץ ביניהם היא הביטוי הרגולרי המבוקש.

מצבים שקולים ומינימיזציה

מילה מפרידה (Separating word) — לשני מצבים q, p ∈ Q, מילה w ∈ Σ* נקראת מפרידה אם בדיוק אחד משני הריצות מסתיים במצב מקבל: δ′(q,w) ∈ F אבל δ′(p,w) ∉ F, או להפך (δ′ — הרחבת פונקציית המעברים למילים).
שקילות־k — p ≡k q אם אין מילה מפרידה באורך ≤ k. שקילות — p ≡ q אם הם k־שקולים לכל k ≥ 0.

מציאת מחלקות שקילות (ל־DFA בלבד)

  1. מסירים את כל המצבים הלא־נגישים.
  2. מתחילים מהחלוקה E0 = {F, Q∖F}.
  3. בצעד k ≥ 1 בונים את Ek: מצבים q, p באותה מחלקה ב־Ek−1 נשארים יחד אם ורק אם לכל σ ∈ Σ מתקיים δ(q,σ) ≡k−1 δ(p,σ).
  4. עוצרים כאשר Ek−1 = Ek.

מינימיזציה של DFA

  1. מריצים את אלגוריתם מחלקות השקילות על Q.
  2. מקצים מצב חדש לכל מחלקת שקילות.
  3. בונים את ה־DFA הממוזער בהתאם.
טענה — שני DFA־ים A, B שקולים (L(A) = L(B)) אם ורק אם qsA ≡ qsB (באוטומט האיחוד שלהם).

למת הניפוח לשפות רגולריות

אם L שפה רגולרית, אז קיים n ∈ ℕ כך שלכל מילה w ∈ L עם |w| ≥ n קיימת חלוקה w = xyz המקיימת:
  1. |y| > 0
  2. |xy| ≤ n
  3. לכל שלם i ≥ 0: wi = xyiz ∈ L
הערת אורך: אם |y| = t אז |xyiz| = |w| + (i−1)t — שימושי כשצריך לפגוע באורך מסוים.

דקדוקים

דקדוק חסר הקשר (CFG) — רביעייה G = (V, Σ, S, R):
  • V — קבוצה סופית של משתנים.
  • Σ — קבוצת הטרמינלים, V ∩ Σ = ∅.
  • S ∈ V — משתנה ההתחלה.
  • R — קבוצה סופית של כללי גזירה מהצורה A → α, כאשר A ∈ V ו־α ∈ (V ∪ Σ)*.
שפה שנוצרת על ידי CFG נקראת שפה חסרת הקשר (CFL) — ושפה היא חסרת הקשר אם ורק אם קיים אוטומט מחסנית שמזהה אותה.
דקדוק רגולרי (RG) — כל כלל הוא מאחת הצורות:
A → w
A → wB
כאשר A, B ∈ V ו־w ∈ Σ*. דקדוק רגולרי פשוט (SRG) — כל כלל מהצורה A → σ (עם σ ∈ Σ), A → σB (עם σ ∈ Σε), או A → ε.

RG ← NFA

  • משתנה לכל מצב; S — המשתנה של qs.
  • לכל מעבר δ(A, σ) = B מוסיפים כלל A → σB; לכל מעבר δ(A, ε) = B מוסיפים A → B.
  • לכל מצב מקבל q ∈ F מוסיפים A → ε.

NFA ← RG (דרך SRG)

  • הופכים את הדקדוק לפשוט (מפצלים A → σ1σ2…σnB לשרשרת כללים באות אחת).
  • מצב לכל משתנה; qs = S.
  • A → σB נותן מעבר δ(A, σ) = B; A → B נותן מעבר ε.
  • לכל A → σ: מוסיפים מצב חדש qi, מעבר δ(A, σ) = qi, ומכניסים את qi ל־F.

פישוט דקדוק ו־CNF

דקדוק מפושט — דקדוק ללא כללי ε (מהצורה A → ε; מותר רק S → ε) וללא כללי יחידה (מהצורה A → B).

הסרת כללי ε

  1. בוחרים כלל A → ε (עם A ≠ S) ומסירים אותו.
  2. לכל כלל B → αAβ מוסיפים (בלי להסיר את המקור) את B → αβ — לכל מופע של A בנפרד: מ־B → αAβAγ נקבל גם B → αβAγ, גם B → αAβγ וגם B → αβγ. עבור B → A מוסיפים B → ε (אלא אם כבר הוסר).
  3. חוזרים עד שלא נותרו כללי ε.

אם ε ∈ L: מריצים את האלגוריתם ואז מוסיפים משתנה התחלה חדש עם S′ → S | ε.

הסרת כללי יחידה

  1. בוחרים כלל יחידה A → B ומסירים אותו.
  2. לכל כלל B → α מוסיפים A → α.
  3. חוזרים עד שלא נותרו כללי יחידה.
צורת חומסקי הנורמלית (CNF) — כל כלל הוא מאחת הצורות:
A → BC
A → σ
כאשר A, B, C ∈ V, B, C ≠ S, ו־σ ∈ Σ. אם ε ∈ L מותר גם S → ε.

CNF ← CFG

  1. מוסיפים משתנה התחלה חדש S′ וכלל S′ → S.
  2. מסירים כללי ε.
  3. מסירים כללי יחידה.
  4. מתקנים את הכללים שנותרו: טרמינל σi בכלל ארוך מוחלף במשתנה Ai עם כלל Ai → σi; כלל A → B1B2…Bn (עם n > 2) מפוצל ל־A → B1C1 ו־C1 → B2…Bn, וחוזר חלילה.

אוטומט מחסנית (PDA)

PDA — שישייה A = (Q, Σ, Γ, δ, qs, F):
  • Q — מצבים; Σ — אלף־בית הקלט; Γ — אלף־בית המחסנית.
  • δ: Q × Σε × Γε → P(Q × Γε) — פונקציית המעברים (קוראים אות או ε, מוציאים סמל מחסנית או ε, דוחפים סמל או ε).
  • qs ∈ Q התחלתי; F ⊆ Q מקבלים.
PDA מפושט — יש לו מצב מקבל יחיד qf; לפני קבלה המחסנית חייבת להיות ריקה; וכל מעבר או מוציא סמל מהמחסנית (pop) או מכניס סמל (push), אך לא שניהם.

PDA ← CFG

בהינתן G = (V, Σ, S, R) בונים PDA עם שלושה מצבים qstart → qloop → qaccept:

  • בכניסה דוחפים S$ (מעבר ε,ε→S$).
  • ב־qloop: לכל כלל A → α1…αk — מעבר ε, A → α1…αk; לכל a ∈ Σ — מעבר a, a → ε.
  • מעבר ε, $ → ε אל qaccept.

CFG ← PDA

בהינתן PDA מפושט P = (Q, ΣP, Γ, δ, qs, {qf}), לכל p, q ∈ Q מגדירים את Lp,q — כל המילים שמריצות את P ממצב p עם מחסנית ריקה למצב q עם מחסנית ריקה. שימו לב: L(P) = Lqs,qf.

בונים דקדוק עם משתנים Ap,q לכל זוג מצבים, S = Aqs,qf, וכללים:

  • לכל p, q, r ∈ Q: Ap,q → Ap,rAr,q.
  • לכל p ∈ Q: Ap,p → ε.
  • לכל p, q, r, s ∈ Q, γ ∈ Γ, σ′, σ″ ∈ Σε כך ש־(r, γ) ∈ δ(p, σ′, ε) (push) ו־(q, ε) ∈ δ(s, σ″, γ) (pop): מוסיפים Ap,q → σ′Ar,sσ″.

למת הניפוח לשפות חסרות הקשר

אם L שפה חסרת הקשר, אז קיים p ∈ ℕ כך שלכל w ∈ L עם |w| ≥ p קיימת חלוקה w = uvxyz המקיימת:
  1. |vy| > 0
  2. |vxy| ≤ p
  3. לכל שלם i ≥ 0: wi = uvixyiz ∈ L
הערת אורך: אם |v| = s ו־|y| = t אז |uvixyiz| = |w| + (i−1)s + (i−1)t.

הצבה (Substitution)

הצבה — בהינתן אלף־ביתים Σ1, Σ2, הצבה היא פונקציה f: Σ1 → P(Σ2*) — לכל אות σ ∈ Σ1 מתאימים שפה Lσ מעל Σ2. ההרחבה למילה: f(w) = {w1w2…wn | wi ∈ f(σi)}; ולשפה: f(L) = ⋃w∈L f(w).
הצבה רגולרית — אם L רגולרית וכל Lσ רגולרית, אז f(L) רגולרית. הצבה חסרת הקשר — אם L חסרת הקשר וכל Lσ חסרת הקשר, אז f(L) חסרת הקשר.

מכונת טיורינג

מכונת טיורינג (TM) — שביעייה M = (Q, Σ, Γ, δ, qs, qacc, qrej):
  • Q — קבוצה סופית של מצבים.
  • Σ — אלף־בית הקלט; תו הרווח ␣ ∉ Σ.
  • Γ — אלף־בית הסרט; ␣ ∈ Γ וגם Σ ⊆ Γ.
  • δ: Q × Γ → Q × Γ × {L, R} — פונקציית המעברים.
  • qs התחלתי; qacc מקבל; qrej דוחה.

השפות המרכזיות

  • ADFA = {⟨D, w⟩ | D is a DFA and D accepts w}
  • ATM = {⟨M, w⟩ | M is a TM and M accepts w}
  • HALTTM = {⟨M, w⟩ | M is a TM and M halts on input w}
  • EDFA = {⟨D⟩ | D is a DFA and L(D) = ∅}
  • ETM = {⟨M⟩ | M is a TM and L(M) = ∅}
  • REGTM = {⟨M⟩ | M is a TM and L(M) is a regular language}
  • EQDFA = {⟨D1, D2⟩ | D1, D2 are DFAs and L(D1) = L(D2)}
  • EQTM = {⟨M1, M2⟩ | M1, M2 are TMs and L(M1) = L(M2)}
  • PAL = {w | w ∈ Σ* and w = wR}
  • PALTM = {⟨M⟩ | M is a TM and L(M) = PAL}
  • L∞ = {⟨M⟩ | M is a TM and L(M) is infinite}
סטטוס כריעות (מהקורס): ADFA, EDFA, EQDFA ∈ R ·  ATM, HALTTM ∈ RE ∖ R ·  ETM ∈ coRE ∖ R ·  REGTM, EQTM ∉ RE ∪ coRE.
